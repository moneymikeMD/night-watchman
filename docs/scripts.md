# scripts.md

The scripts reference is generated from `scripts/*.sh` and `scripts/*.py`
headers by `scripts/gen-reference-docs.sh` into
`docs/preview/website/src/content/docs/reference/scripts.mdx`, so a
script's own header is the single source of truth while it is in use.

This file holds only the `## Retired` section that ai-toolkit's
`script-retire.sh --yes` appends to when it deletes a script under the
usage rule (`report --usage` flagged `retire?`). A retired script's history
is in git; nothing else is recorded here.
