## Hook scripts

### hooks/bash-result-shunt.sh

bash-result-shunt.sh — Claude Code PreToolUse hook for Bash. Attacks the
largest known-noisy Bash tool results (uncapped `git log`, `jira-api.sh
board`/`raw` search pulls) before they land in the calling model's
context.

### hooks/guard-fs-writes.sh

guard-fs-writes.sh — Claude Code PreToolUse hook for the Bash tool.

### hooks/read-shunt.sh

read-shunt.sh — Claude Code PreToolUse hook for Read (and simple `cat`
Bash calls). Copies Portal by Spotify's read-shunt mechanism
(https://engineering.atspotify.com/2026/9/portal-by-spotify-cut-my-claude-code-token-usage-by-90),
deliberately scoped narrow: READS ONLY, never edits, reasoning, or safety
review.

### hooks/script-events-hook.sh

script-events-hook.sh — Claude Code SubagentStop hook.
Feeds every finished `script-author`/`script-reviewer` Agent-tool
subagent into the existing lifecycle extractor
(scripts/script-analytics.py extract, see docs/cost.md "Script
lifecycle analytics") automatically, so the events log stops depending
on someone remembering to run `extract` by hand after the fact.
